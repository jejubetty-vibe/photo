# 🎄 크리스마스 카드 메이커 (Christmas Card Maker)

내 사진과 손글씨 편지, 크리스마스 일러스트로 나만의 포토 엽서를 만들고 4×6 사진으로 저장하는 웹 애플리케이션입니다.

## 💻 컴퓨터에서 바로 실행하기 (로컬 실행)
- 압축을 푼 폴더에서 **`index.html` 파일을 더블클릭**하면 크롬, 엣지, 웨일, 사파리 등 모든 브라우저에서 인터넷 연결 없이도 즉시 실행됩니다!
- *(CORS 브라우저 보안 제한을 완벽하게 해결하도록 자바스크립트 엔진이 HTML 내부에 완벽히 내장되어 있습니다.)*

## 🚀 깃허브 배포 (GitHub Pages) 초간단 3단계

1. **깃허브 저장소(Repository) 생성 & 파일 업로드**:
   - GitHub(https://github.com)에서 **New repository**를 생성합니다 (예: `christmas-card`, Public 설정).
   - 다운로드한 파일들을 저장소 최상위(Root)에 업로드(Push)합니다:
     - `index.html` (핵심 실행 파일)
     - `assets/` (배경 이미지 폴더)
     - `style.css`, `script.js`, `README.md`

2. **GitHub Pages 활성화**:
   - 저장소 상단 메뉴의 **Settings** 클릭
   - 좌측 사이드바의 **Pages** 클릭
   - **Build and deployment** > **Source**: `Deploy from a branch` 선택
   - **Branch**: `main`(또는 `master`), 폴더: `/(root)` 선택 후 **Save** 클릭

3. **배포 주소 확인**:
   - 약 1~2분 뒤 상단에 표시되는 `https://<내깃허브아이디>.github.io/<저장소이름>/` 주소로 접속하면 누구나 카드를 만들 수 있습니다!
